# UI設計 (design-ui)

## 画面一覧

| ID | 画面 | 概要 |
|----|------|------|
| S-1 | ホーム | 録画 / スクショ の2大ボタン + 出力先トグル |
| S-2 | 範囲選択オーバーレイ | Cmd+Shift+4風の十字カーソルでドラッグ選択 |
| S-3 | 録画中UI | フローティング停止バー (+メニューバーアイコン) |
| S-4 | 注釈エディタ | スクショ撮影後に開く。Awesome Screenshot風 |
| S-5 | 設定 | 画質プリセット・波紋スタイル・保存先など |

## S-1: ホーム画面

```
┌──────────────────────────────────────┐
│  mp4recorder                    ⚙️   │
│                                      │
│   ┌──────────────┐ ┌──────────────┐  │
│   │      ●       │ │      ✂️      │  │
│   │     録画      │ │    スクショ    │  │
│   └──────────────┘ └──────────────┘  │
│                                      │
│  出力先:  [ 📋 クリップボード | 💾 ファイル ] │
│  録画範囲: [ 画面全体 ▾ ] (ディスプレイ選択) │
│  波紋:    [ リング ▾ ]                │
└──────────────────────────────────────┘
```

- 出力先トグルはスクショ・録画共通の設定として常時見える位置に置く
- 「録画」押下 → 範囲選択 (or ディスプレイ全体なら即) → カウントダウン(3秒) → 録画開始、ウィンドウは最小化
- 「スクショ」押下 → アプリウィンドウを隠して S-2 へ

## S-2: 範囲選択オーバーレイ

- 全ディスプレイに半透明の暗幕 + 十字カーソル
- ドラッグで矩形選択。選択中はサイズ (px) を表示
- `Space` でウィンドウ選択モードに切替 (ホバーでウィンドウをハイライト) — 推奨機能
- `Esc` でキャンセル
- Enter / マウスアップで確定
- マルチモニター: 暗幕は各ディスプレイに出す。選択はまず単一ディスプレイ内を必須とする

## S-3: 録画中UI

- 画面下部中央に小さなフローティングバー:
  `[■ 停止]  00:23  ● REC`
- バー自体は録画に写り込まないようにする (ScreenCaptureKitの除外ウィンドウ指定)
- メニューバーアイコンでも停止できる
- 停止 → エンコード完了 → 出力先設定に従い コピー or 保存 → 通知

## S-4: 注釈エディタ (Awesome Screenshot 踏襲)

```
┌────────────────────────────────────────────────┐
│ [↩][↪] | [▭][◯][─][→][✎][T][#][▒] | 色● 太さ— │ ← ツールバー
│                                                │
│                 (キャプチャ画像)                  │
│                                                │
│         [トリミング]   [📋 コピー] [💾 保存]      │
└────────────────────────────────────────────────┘
```

ツール:

| ツール | 動作 |
|--------|------|
| ▭ 矩形 | ドラッグで枠線の四角。塗りなし/ありオプション |
| ◯ 楕円 | 同上 |
| ─ 直線 / → 矢印 | ドラッグで描画 |
| ✎ フリーハンド | ペン描画 |
| T テキスト | クリック位置にテキストボックス。フォントサイズ変更可 |
| # 番号バッジ | クリックごとに ①②③… を配置 (手順説明用) |
| ▒ ぼかし | ドラッグ範囲をモザイク/ブラー (機密マスク用) |
| 選択ツール | 描いたオブジェクトを移動・リサイズ・削除 |

- 色パレット: 赤(デフォルト)・オレンジ・黄・緑・青・紫・黒・白 + 自由選択
- 線の太さ: 細 / 中 / 太
- Undo/Redo: Cmd+Z / Cmd+Shift+Z
- 完了操作: 「コピー」(クリップボード) / 「保存」(ファイル)。デフォルトはホームの出力先設定に従い、ボタンで上書き可能
- 実装: Flutter の `CustomPainter` + オブジェクトリスト (→ data-model.md の `Annotation`)

## S-5: 設定画面

- 画質プリセット (軽量 / 標準 / 高画質) + fps・スケールの個別調整 (上級者向け折りたたみ)
- 波紋スタイル選択 (プレビュー付き): リング / 塗り円 / 二重リング / ハイライト
- 波紋の色・サイズ
- 保存先ディレクトリ・ファイル名テンプレート (`rec_{yyyyMMdd_HHmmss}.mp4` 等)
- ショートカットキー設定 (推奨機能)
- 権限ステータス表示 (画面収録 / アクセシビリティ) + 設定アプリを開くボタン

## デザイントーン

- Tailwindは使えないため、Flutterのテーマで**Tailwindのデザイントークンを再現**する
  (色は Tailwind のパレット slate/blue、角丸 8px、余白は4pxグリッド)
- ダークモード追従 (macOSのシステム設定に従う)
