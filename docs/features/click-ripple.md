# 機能仕様: クリック波紋 (リップル)

対応要件: FR-1.4, FR-1.5

## 概要

録画中、マウスクリックした位置に波紋アニメーションを表示する。
波紋は**画面最前面の透明オーバーレイに描画**され、画面キャプチャに自然に写り込む (後合成しない)。

## 動作

- 有効期間: **録画中のみ** (通常時は出さない。設定で常時ONも可 — 低優先)
- 左クリック・右クリック・ドラッグ開始で発火 (右クリックは色違いにする — 推奨)
- 連打時は波紋が重なって複数表示されてよい

## スタイル (FR-1.5)

data-model.md `RippleStyle` 参照。設定画面でプレビュー付きで選択。

| スタイル | アニメーション (durationMs=500 既定) |
|----------|--------------------------------------|
| ring | 半径 8→40px に拡大しつつ線が細く・透明に |
| filledCircle | 半径 30px の塗り円が opacity 0.5→0 |
| doubleRing | ring を 120ms 差で2発 |
| highlight | 半径 24px の塗り円が 200ms 表示→300msでフェード |

色・最大サイズ・時間は設定可能。既定色は黄 (どんな背景でも視認しやすい)。

## 技術詳細 (Swift)

### クリック検知

- `NSEvent.addGlobalMonitorForEvents(matching: [.leftMouseDown, .rightMouseDown])`
  - グローバル監視には**アクセシビリティ (または入力監視) 権限**が必要
  - 権限がない場合: 波紋なしで録画は続行し、初回に案内を出す (録画自体をブロックしない)
- 取得座標はグローバル座標 (左下原点) → オーバーレイのローカル座標へ変換

### オーバーレイウィンドウ

- `NSScreen.screens` ごとに1枚、ボーダレス透明 `NSWindow`
  - `level = .screenSaver` (最前面)
  - `ignoresMouseEvents = true` (クリック透過 — これがないと操作不能になる)
  - `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]` (Spaces/フルスクリーンでも出す)
  - `sharingType` は既定のまま (キャプチャに**写す**必要があるため `.none` にしない)
- 描画: `CAShapeLayer` + `CABasicAnimation` (半径・opacity)。終了後レイヤー破棄
- ディスプレイ構成変更 (`NSApplication.didChangeScreenParametersNotification`) でオーバーレイを再構築

### 注意点

- 波紋がフローティング停止バーと重ならないよう、停止バーは `level` をさらに上にする
  (停止バーはキャプチャ除外、波紋オーバーレイは除外しない、の区別に注意)
- fps=10 の録画では 500ms の波紋が約5フレームしか写らない。**波紋の視認性が低ければ duration 既定を 700ms 程度に伸ばす** (実装後に実機確認)

## 受け入れ基準

- [ ] 録画したmp4にクリック波紋が写っている (fps=10でも視認できる)
- [ ] 波紋表示中も下のアプリを普通に操作できる (クリック透過)
- [ ] 外部ディスプレイ上のクリックにも波紋が出る
- [ ] 4スタイルすべて切替可能で、設定が永続化される
- [ ] アクセシビリティ権限がなくても録画自体はできる
