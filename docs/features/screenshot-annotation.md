# 機能仕様: スクリーンショット + 注釈エディタ

対応要件: FR-2, FR-3。Awesome Screenshot のデスクトップ版を目指す。

## ユーザーフロー

1. ホームで「スクショ」押下 (またはグローバルショートカット)
2. アプリウィンドウが隠れ、範囲選択オーバーレイ (S-2) が全ディスプレイに出る
   - ドラッグ → 範囲キャプチャ
   - `Space` → ウィンドウ選択モード (推奨機能)
   - `Esc` → キャンセル
3. キャプチャ確定 → 注釈エディタ (S-4) が開く
4. 注釈を描く (矩形・矢印・テキスト・ぼかし・番号バッジ…)
5. 「コピー」or「保存」で完了
   - コピー: PNG画像をクリップボードへ (Awesome Screenshotと同じくPRやSlackに直接貼れる)
   - 保存: `shot_YYYYMMDD_HHmmss.png`

「注釈なしで即コピー」したいケースのため、エディタを開かず即出力する**クイックモード** (Shift押しながら確定) を推奨機能として用意。

## 範囲選択の詳細

- 撮影は選択確定後に行うのではなく、**オーバーレイ表示直前に全画面を先にキャプチャ**し、
  そのフリーズ画像の上で範囲選択する (Cmd+Shift+4と違い、選択中に画面が動かない。ツールチップ等を撮りやすい)
- 選択中はカーソル座標と選択サイズ (W×H px) を表示
- Retinaは物理解像度でキャプチャ (スクショは画質優先。録画と方針が違う点に注意)
- マルチモニター: 各ディスプレイを個別にキャプチャ+暗幕。選択は単一ディスプレイ内 (またぎは open-questions)

## 注釈エディタの詳細

ツール仕様・UIは [design-ui.md S-4](../design/design-ui.md) 参照。実装ポイント:

- Flutter `CustomPainter` で `List<Annotation>` を描画 (モデルは data-model.md)
- 選択ツール: ヒットテスト → ドラッグで移動、ハンドルでリサイズ、Delete で削除
- テキスト: ダブルクリックで再編集
- ぼかし: 対象矩形の元画像ピクセルを縮小→拡大 (モザイク)。`ImageFilter.blur` でも可
- 番号バッジ: 配置ごとに自動インクリメント。削除すると以降を振り直す
- Undo/Redo: 操作単位のスナップショット方式
- 出力合成: `ui.PictureRecorder` で元画像+注釈を描いて `toImage` → PNG
- トリミング (FR-2.7): エディタ内でクロップ枠を再調整

## エラーケース

| ケース | 挙動 |
|--------|------|
| 画面収録権限なし | 案内ダイアログ → システム設定へ |
| 選択サイズが極小 (<4px) | 無視してオーバーレイ継続 (誤クリック対策) |
| エディタを閉じる (未保存) | 確認ダイアログ「コピーせず破棄しますか?」 |

## 受け入れ基準

- [ ] 範囲選択→注釈→クリップボードコピー→GitHub PRコメントに Cmd+V で貼れる
- [ ] 全注釈ツール (矩形/楕円/線/矢印/フリーハンド/テキスト/バッジ/ぼかし) が動く
- [ ] 色・太さ変更、Undo/Redo が動く
- [ ] Retinaで文字が滲まない (物理解像度キャプチャ)
- [ ] 外部ディスプレイでも範囲選択できる
