# 要件定義 (requirements)

## プロダクト概要

Web開発のPRに載せる「証跡」(エビデンス) を手軽に取るための macOS デスクトップアプリ。
録画 (mp4) とスクリーンショット (注釈付き) の2機能を持つ。

- 対象OS: macOS のみ
- 利用者: 自分 (個人利用)。エンジニア向け
- 収益化: しない

## 背景・課題

- PRに動作証跡 (動画・画像) を載せたいが、無料で使いやすい録画アプリがない
- GitHub に添付する以上、**ファイルサイズが軽いことが最優先**
- スクショは Awesome Screenshot を使っているがブラウザ内しか撮れない。デスクトップ全体で同等の注釈機能が欲しい
- 現状は `Cmd+Shift+4` + クリップボードコピーで代用している

## 機能要件

### FR-1: 画面録画

| # | 要件 | 優先度 |
|---|------|--------|
| FR-1.1 | mp4 (H.264) で保存する | 必須 |
| FR-1.2 | できる限りファイルサイズを小さくする (低fps・低ビットレート・解像度ダウンスケール)。**カクつき・画質低下は許容する** | 必須 |
| FR-1.3 | マウスカーソルを録画に含める | 必須 |
| FR-1.4 | クリックを検知して、クリック位置に波紋 (リップル) を表示し、録画に写り込ませる | 必須 |
| FR-1.5 | 波紋のスタイルを複数から選択できる (例: リング / 塗り円 / 二重リング / ハイライト) | 必須 |
| FR-1.6 | 録画範囲: 画面全体 / 特定ディスプレイ / 範囲選択 | 全体・ディスプレイ選択は必須、範囲選択は推奨 |
| FR-1.7 | 録画の開始・停止が簡単にできる (停止はメニューバー or フローティングボタン) | 必須 |

### FR-2: スクリーンショット + 注釈

Awesome Screenshot の操作感を踏襲する。

| # | 要件 | 優先度 |
|---|------|--------|
| FR-2.1 | 範囲選択してキャプチャ (画面全体・ウィンドウ単位も可) | 必須 |
| FR-2.2 | キャプチャ後に注釈エディタが開く | 必須 |
| FR-2.3 | 注釈ツール: 矩形 / 楕円 / 直線 / 矢印 / フリーハンド / テキスト / ぼかし(モザイク) / 番号バッジ | 必須 |
| FR-2.4 | 色・線の太さ・フォントサイズを選べる | 必須 |
| FR-2.5 | Undo / Redo | 必須 |
| FR-2.6 | 注釈オブジェクトは後から選択して移動・削除できる | 推奨 |
| FR-2.7 | トリミング (撮った後に切り抜き) | 推奨 |

### FR-3: 出力

| # | 要件 | 優先度 |
|---|------|--------|
| FR-3.1 | 出力先を **クリップボードにコピー / ファイル保存** から選べる (スクショ・録画とも。録画のクリップボードはファイル参照コピー) | 必須 |
| FR-3.2 | ファイル保存先ディレクトリ・ファイル名規則を設定できる | 推奨 |
| FR-3.3 | 保存完了後に通知 + Finderで表示 / パスコピーの導線 | 推奨 |

### FR-4: アプリ全体

| # | 要件 | 優先度 |
|---|------|--------|
| FR-4.1 | 起動するとホーム画面に「録画」「スクショ」の2大ボタンがある | 必須 |
| FR-4.2 | **マルチモニター対応** (どのディスプレイでも撮れる・波紋も全ディスプレイで出る・範囲選択もディスプレイをまたげる※) | 必須 (※またぎは要検討 → open-questions) |
| FR-4.3 | 設定の永続化 (波紋スタイル・出力先・画質プリセット等) | 必須 |
| FR-4.4 | グローバルショートカットキー | 推奨 |

## 非機能要件

| # | 要件 |
|---|------|
| NFR-1 | ファイルサイズ優先。目安: 1080p・30秒の操作録画で 1〜3MB 程度を目標 (GitHubの添付上限10MBに余裕を持って収まる) |
| NFR-2 | 録画中のCPU負荷でPC作業が妨げられないこと (低fpsで軽くする) |
| NFR-3 | macOS の画面収録権限・アクセシビリティ権限を初回に案内する |
| NFR-4 | 無料・OSS的に自分でビルドして使える |

## スコープ外 (今はやらない)

- 音声録音 (マイク・システム音声)
- 動画の編集 (トリム・カット)
- GIF出力 (将来検討 → open-questions)
- Windows / Linux 対応
- 配布 (App Store / notarization)
